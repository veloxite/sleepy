Sleepy is an open source, privacy focused tool. Visit github/original website for more info. I created this because I was bored and wanted to do something cool.

MIT licensed. Project links will be added when the public repository is published.

You decide what Sleepy sees.

Screen on sends a fresh screenshot to your selected provider with each message. A focus area limits captures to that part of the primary screen. Screen off sends text, including any attached document. There is no background recording.

Chats and memories are stored in this project’s data folder. Screenshots stay in memory and are not saved to chat history. Recent chat context and saved memories are included in AI requests.

Cloud-synced folders can sync your local data. Screen-reading models can make mistakes; verify the transcribed problem before relying on a solution.
