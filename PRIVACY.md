# Sleepy privacy

This document describes Sleepy 0.1.0, the Windows desktop release. Sleepy lets
you choose your AI provider and use your own API key. Privacy does not mean
everything stays offline: the features below send data to services you choose
or use. Those services have their own retention rules and privacy policies.

## What stays on your device

Sleepy stores chat messages and titles, drafts, settings, your editable memory
note, workspace presets, connection details (such as model names and API
addresses), and usage counters locally. Custom companion logos are copied into
the local data folder. Image-search thumbnails can be saved in chat history.

For the installed and portable Windows apps, the folder is
`%LOCALAPPDATA%\Sleepy`. Source installations use the project's `data/` folder.
The portable app also uses your Windows profile; personal data does not travel
with its extracted program folder. Future macOS/Linux builds use the locations
documented in [DISTRIBUTION.md](DISTRIBUTION.md).

The chat database is **not encrypted by Sleepy**. Someone with access to your
Windows account, backups, or synced folders may be able to read it. Cloud backup
and folder-sync software can copy local files independently of Sleepy.

Screen captures are held in memory for the current request and preview, rather
than saved in the chat database. Old screenshots are not attached to follow-up
messages. A screen-context marker and the model's description of the screen can
remain in saved chat text. Attached document text is read locally and held for
the current chat session; extracted document text is not separately saved in
history, but answers can quote or describe it. Your original files remain where
you placed them.

## What leaves your device

- **AI conversations:** Sleepy sends your message, recent conversation context
  (up to 16 prior text messages), your memory note, and applicable instructions
  to the selected AI provider. When enabled, screen context includes a fresh
  screenshot or selected screen area. Attached documents contribute extracted
  text, currently limited to 24,000 characters. Tool requests and results can
  also become conversation context. The provider receives your API credential
  to authenticate requests; the credential is not included as chat text.
- **Local models:** an Ollama connection to localhost sends AI requests to that
  local server. Other enabled features can still contact online services.
- **Connection checks:** loading models and checking usage contact the saved
  provider. Testing a model makes a small request; the screen-model test sends
  a generated test image, not a desktop screenshot. These requests may use quota.
- **Push-to-talk:** Sleepy records while you hold the microphone control, up to
  30 seconds, then sends the recording to the configured supported speech
  connection (Groq or OpenAI) for transcription. Recording stops when released.
  Sleepy does not save the recording in chat history; the resulting text can
  become a saved message and be sent to your chat provider.
- **Read aloud:** Natural voice sends reply text to Microsoft's online speech
  service through edge-tts. It does not require Windows or Edge to be installed.
  System voice uses the operating system speech engine instead; its behavior
  depends on your OS and installed voice. Sleepy does not send system-voice
  text through edge-tts.
- **Images, video, and music:** image search sends search terms to Wikimedia
  Commons and downloads thumbnails. YouTube searches contact YouTube.
  SoundCloud searches and streaming contact SoundCloud and media hosts.
  Searches can be generated by the AI from your request. These services receive
  the search/media requests and normal network information such as your IP
  address. Local audio playback does not require a SoundCloud search.
- **Websites and GitHub:** opening a link uses your browser and that site's
  privacy rules. The optional GitHub plugin sends its token to GitHub to check
  the account and create repositories you approve. It does not give that token
  to the AI. Public repository names and descriptions may be prepared by your
  selected model as part of the conversation.

Sleepy does not continuously capture your screen or silently switch AI
providers when a request fails. There is no built-in Sleepy analytics or
advertising service in this version. External services can still keep their
own access logs. Check your provider's policies before sharing sensitive data.

## API keys and other credentials

Keys entered in Settings are stored using the operating system credential
vault through keyring (Windows Credential Manager in this release), separately
from the chat database. The GitHub token uses the credential vault too. Saved
provider metadata, usage counters, and model choices are stored in the database.
Keys are not intended to appear in application logs, exports, or AI messages.
Avoid pasting a key into a chat, screenshot, document, or bug report: Sleepy
cannot reliably remove secrets from content you deliberately share.

Developer source installations can optionally read legacy credentials from
environment variables or a local `.env` file. Packaged apps do not load `.env`.
Removing a saved connection attempts to remove its vault key; it does not erase
a credential you separately placed in `.env` or your environment. Revoke keys
at the provider if you need to invalidate them completely.

## Deleting conversations and memory

Deleting a conversation removes its messages and saved draft from Sleepy's
active database. It does **not** securely overwrite the database file, clear
backups or exports, remove information already sent to a provider, or delete
your separate memory note and settings. Database remnants may remain on disk.
Clear or edit the memory note in Settings separately. Delete exported Markdown
files and backups yourself if you no longer want them.

To request deletion of data held by an AI, speech, or media service, follow that
service's process. Removing something in Sleepy cannot recall a completed
network request.

## Uninstalling and removing local data

Uninstalling the Windows app removes program files but intentionally preserves
your local chats, settings, logos, and vault credentials for future installs.
Deleting the portable program folder also leaves this profile data behind.

For a fuller cleanup:

1. Remove saved AI connections in Settings and disconnect the GitHub plugin.
2. Quit Sleepy completely, including its tray companion.
3. Delete `%LOCALAPPDATA%\Sleepy` (or `data/` for a source installation) after
   saving anything you want to keep.
4. Review Windows Credential Manager for remaining Sleepy entries. Remove
   unneeded credentials, and revoke provider/GitHub keys if appropriate.
5. Separately remove exports, backups, synced copies, and any developer `.env`
   files or environment variables you created.

Ordinary file deletion is not a guarantee of secure erasure. These steps do not
delete your original attached documents or undo files and repositories you
created through Sleepy's tools.

## Questions and changes

Sleepy is open source: [inspect the code or report an issue](https://github.com/veloxite/sleepy).
GitHub issues are public; never include API keys, private chats, recordings, or
unredacted screenshots. This document describes the current implementation,
not a guarantee about third-party services. Future versions may change these
behaviors and should update this document accordingly.
